# Charter — O.K. Film (Production Company / Agency)
**Owns.** Client briefs, scheduling, production and editing coordination, delivery checklists.
**Workflow v0.1.** `okfilm.production_plan`: read an approved brief and task list → record each dated constraint with its file:line → report missing information → schedule backwards from delivery with deterministic date arithmetic → `production-plan.md` → human review.
**Worker tools.** list_sources, read_source, date_math, record_evidence, report_missing, write_artifact.
**Never.** Sends a message, prepares or sends an invoice, publishes, or contacts a client. Those are future `action` approvals with a named destination.
**Acceptance.** Dates and constraints trace to the brief; assumptions are listed as assumptions; the owner accepts the specific artifact version.
**Status.** One live run on a synthetic brief reached review on 2026-11-17. No real client data has been used.
